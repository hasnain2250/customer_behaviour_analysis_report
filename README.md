# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using Python, MySQL, and Power BI to transform raw retail transaction data into meaningful business insights.

The project follows a complete end-to-end analytics workflow including data preprocessing, feature engineering, SQL analysis, and interactive dashboard development.

---

## 🎯 Business Problem

Retail businesses generate large volumes of customer transaction data but often struggle to convert it into actionable insights.

The goal of this project is to answer important business questions such as:

- Which customers generate the highest revenue?
- Which products receive the highest discounts?
- How do subscriptions affect sales?
- Which customer segments are most valuable?
- Which age groups contribute the most revenue?
- How can customer retention be improved?

---

## 📊 Dataset

- **Total Records:** 3,900

# 💡 Key Business Insights

✔ Male customers generated higher total revenue.

✔ Young Adults contributed the highest revenue among all age groups.

✔ Clothing generated the highest overall sales.

✔ Hat, Sneakers, and Coat received the highest discount rates.

✔ Loyal customers represented the largest customer segment.

✔ Express shipping showed a slightly higher average purchase amount than Standard shipping.
